# Portafolio Cyberpunk

Portafolio profesional de **Keyther Alejandro García Martínez**, Desarrollador Full-Stack e Ingeniero de IA, con estilo futurista en azul neón, modo oscuro y diseño responsivo.

- Repositorio: https://github.com/keythergarcia0-design/cyberpunk_portfolio
- Sitio publicado: https://keythergarcia0-design.github.io/cyberpunk_portfolio/

## Tecnologías
- HTML5, CSS3 y JavaScript
- Bootstrap 5 y Bootstrap Icons (CDN)
- Devicon y Font Awesome para los logos (CDN)
- Fuentes Orbitron y Rajdhani (Google Fonts)

## Secciones
- Navbar flotante
- Hero con avatar cyberpunk, biografía y redes
- Sobre mí con datos de contacto
- Stack tecnológico con tarjetas de efecto neón al pasar el cursor
- Proyectos con filtros interactivos (Todos, Web, IA, Backend)
- Certificaciones y formación
- Footer con logos de redes sociales y botón "Volver arriba"

## Estructura
```
cyberpunk_portfolio/
├── index.html
├── style.css
├── script.js
├── foto.jpg   (opcional)
└── README.md
```

## Cómo personalizarlo
- Foto real: guárdala como `foto.jpg` y reemplaza al avatar automáticamente.
- Proyectos: edita la lista `projects` en `script.js`.
- Certificaciones: edita la lista `certs` en `script.js`.
- Enlaces y contacto: están en `index.html` (secciones Hero, Sobre mí y footer).

## Publicación
Desplegado con GitHub Pages desde la rama `main`, carpeta raíz.
